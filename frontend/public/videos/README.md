# Landing page videos

Put the Huzzler explainer here as **`huzzler-intro.mp4`** (H.264 + AAC, 1080p or 720p).
It plays in the "The problem" section of the home page.

Optional: **`huzzler-intro-poster.jpg`**, the still shown before playback (16:9, e.g. 1280×720).

Until `huzzler-intro.mp4` exists, the page shows an animated "video coming soon" card instead.

Keep the file under about 50 MB so it loads quickly on mobile data; files in `public/` are served
as-is by the web app.
